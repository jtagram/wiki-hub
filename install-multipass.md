# Instalar Multipass en Ubuntu Server

Multipass crea máquinas virtuales Ubuntu desde la terminal.

## 1. Instalar

```bash
sudo snap install multipass
```

## 2. Verificar

```bash
multipass version
```

Debe mostrar la versión instalada, por ejemplo:

```
multipass   1.14.0
multipassd  1.14.0
```
