# Cómo funciona iam

`iam` es la aplicación web donde el personal interno administra las aplicaciones, los roles y los usuarios del ecosistema. Todo se guarda en `iam-api`, que es el único que valida credenciales y emite el JWT con el que las demás aplicaciones autorizan a sus usuarios.
