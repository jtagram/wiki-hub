# Cómo funciona ticket-hub

`ticket-hub` es la aplicación web donde el personal interno pide cambios de infraestructura mediante tickets. Cada pedido se guarda como un ticket; cuando un aprobador lo aprueba, se ejecuta sobre el servidor, Kubernetes o la base de datos a través de `infra-hub-api`. Desde la misma aplicación se pueden ver y buscar los tickets ya creados.
